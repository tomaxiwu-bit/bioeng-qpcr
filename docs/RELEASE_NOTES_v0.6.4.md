# 0.6.4：P1 分析能力接入

## qPCR

相对定量可选多个内参。ΔΔCt 保留目标与所有内参近似等效率、约为 100% 的显式确认；
效率校正方案逐检测项目要求实测效率和依据，不用默认值代替实测。
效率采用小数：`0.95` 为 95%，每周期扩增因子为 `1 + efficiency`。

复用既有 `normalized_quantity`：每个基因先按技术重复汇总 Cq，再计算效率校正数量，
多个内参数量取几何均值，最终除以所选校准样品的标准化量。
单内参时与 Pfaffl 等价；均取 100% 时与 ΔΔCt 等价。缺失任一所选内参的样品明确排除，
校准样品缺失则阻止定量，不使用剩余内参替代。

效率证据保存在分析设置中，修改只使定量和报告失效，保留采集数据和质控。
旧项目继续支持 `reference_id`，新项目可以使用 `reference_ids`；备份恢复保持兼容。
多内参不代表已验证内参稳定性；本轮未新增组间统计推断。

## 酶动力学

新增“全局拟合与模型比较”，复用已有五类抑制模型，显示 AICc、ΔAICc、BIC、
Akaike 权重、参数标准误、原始速率拟合和残差。
候选模型证据接近、收敛不充分或无法计算 AICc 时，提示机制未决。
Akaike 权重不是机制正确的概率，标准误不是置信区间。

比较在后台执行；取消请求会在当前比较结束后丢弃结果。
参数趋势判别保留为辅助入口，不替代全局比较。

## 效价批量审阅

新增化合物搜索、审阅状态筛选、每页 20 条分页、单项详情和全量 CSV 导出。
失败项与成功项均保留；拟合成功、需复核、检查通过和未审计分别展示。
汇总提示同步反映逐项审阅状态，不将规则通过等同于所有结果可信。
任意化合物均可从本地记录按需生成曲线和残差，不再受初始前三项预览限制。
使用保存的拟合参数及观测值，不重复拟合、重采样或模型选择。

新记录包含绘图数据；旧记录需重新计算一次以生成完整绘图记录。
外部备份需复算后才能使用曲线审阅与汇总导出。完整原始备份仍可下载。
本轮支持逐化合物 SVG / PDF / PNG 下载，未增加全批图表 ZIP 或后台任务队列。

八个模块入口与已有项目均保留。酶、发酵和 FBA 的统一历史及 P2 场景扩展仍待完成。
