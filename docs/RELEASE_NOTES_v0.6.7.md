# 0.6.7：工程收尾与研究模块收敛

本地维护版本，基于现有 Python / Flask / Qt 技术栈，不推送或发布到 GitHub。

* 修复对接 CLI 导出：`ligand.elements` 来自真实原子元素，残基名单独导出。
  CLI 与浏览器/桌面共用复核结论，附检查证据；网格完成不称作全局收敛。
* 效价、对接、序列绘图异常记录日志并返回 `plot_warnings`，浏览器明确提示。
  数值结果仍可存档，告警随备份保留，不将绘图失败伪装成完整成功。
* 浏览器记录和每个 qPCR 分析历史版本增加软件、依赖、时间、输入摘要和参数。
  报告展示历史环境。旧备份保持兼容，不追填当前版本；外部结果仍须复算。
* 发布包补入项目 MIT 许可证、第三方原始许可、组件清单、对应版本源码、
  构建环境及精确项目源码快照。打包排除未使用的 Qt PDF / 虚拟键盘插件，
  及其 QML / Quick 依赖与可选软件 OpenGL 回退。
* 五个主要模块：qPCR、效价、酶动力学、发酵动力学、FBA。通用文件预览改为
  辅助工具；简化对接、通用序列比对移出主页与桌面主导航，保留旧版入口、
  计算 API、库和历史恢复。没有删除用户数据库或原始数据。
* 公共基准增加执行环境，保留拟合失败和设计排除明细；澄清参考区间命中率
  不是自身置信区间的覆盖率，成功率仅适用于筛选后的可评估曲线。
  修正 OpenADMET 下载与 Windows 检出文件的 LF/CRLF 校验差异，分别固定哈希，
  不跳过完整性检查，并在新报告中记录实际输入哈希。
* 补充贡献/支持指南、固定环境验证与构建文档，修正工作台备份导入和浏览器
  模块说明。源码分发包含锁文件与打包配置；增加固定环境 CI 验证。

## 迁移

默认数据库位置不变。新运行追加结果；导入备份创建新记录/新项目。
移出主导航的功能位于首页“辅助工具与旧版兼容入口”；旧 URL 与历史链接仍有效。
原独立桌面计算仍不自动归档，需要统一历史时使用浏览器。

## 后续边界

本轮没有增加机器学习、数字 PCR 或 CRISPR 分析引擎；候选方向及验收要求见
`MODULE_ROADMAP.md`。没有补造真实实验室使用证据、作者信息或 JOSS 投稿稿件。
