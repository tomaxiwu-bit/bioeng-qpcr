# bioeng-qpcr 0.6.0 — 实验工作台

0.6.0 将一次 qPCR 实验的设计、采集与分析放到同一个持久化工作流中。
桌面程序默认显示工作台入口，在本机浏览器打开；原有独立分析模块继续可用。

## 新增能力

- 八阶段工作流：样品与引物/探针、反应体系与 96/384 孔板设计、温度循环与通道、
  运行快照与数据采集、Ct 与熔解峰、质控、相对/绝对定量、结果与报告。
- SQLite 本地项目、乐观并发检查、不可变运行设计快照与分析版本历史。
  上游变化使下游结果失效；质控 FAIL 阻止定量，但可导出问题报告。
- CSV/RDML 采集文件严格匹配设计；支持源文件 Ct 和显式配置的阈值 Ct。
- 两套带出处、固定上游版本、SHA-256 和许可的公开数据演示；缺失证据保持缺失。
- 五套可编辑实验设计模板，六套图表/报告主题；技术重复叠加、熔解峰标记、
  标准曲线残差图，以及相对表达棒棒糖/柱状/点图。
- CSV、项目 JSON、自包含 HTML 报告，以及 SVG/PDF/300 dpi PNG 图表导出。

## Windows 发布修复

- 移除打包配置对 Flask、Jinja2 和 openpyxl 的排除，纳入工作台页面、公开数据与许可。
- 打包自检除 GUI 和既有科学计算外，还验证模板库、SQLite、两套示例完整流程、
  公开 Ct 示例的 5.637283 倍结果，以及报告内嵌 SVG / PNG 导出。
- 便携包保留 EXE、完整 `_internal`、逐文件 SHA-256 清单及外部 ZIP 校验文件。

## 使用

解压完整 ZIP，运行 `bioeng-qpcr.exe`，点击“打开实验工作台”。使用期间保持桌面程序
开启。本地服务只监听 `127.0.0.1`。数据默认位于
`%LOCALAPPDATA%/bioeng-qpcr/workbench.sqlite3`；程序文件夹和项目数据库分别保存。

## 范围

- 尚未接入厂商 SDK，不控制真实热循环仪；采集使用文件导入或公开数据回放。
- 质控阈值和 ΔΔCt 效率假设需按实验室 SOP 确认；结果不是 MIQE 完整合规认证。
- 实验模板不包含测量值。第三方公开演示数据按各自许可分发。
- Windows 便携版未代码签名，没有自动更新器。

详细模块、页面、数据模型、状态与接口见 [工作台设计](QPCR_WORKBENCH.md)。
