# 0.6.1：综合入口与模块导航

解决默认只显示 qPCR、让其他实验模块看起来消失的问题。

- 新增 `/lab` 首页：八个模块并列，支持搜索并标明浏览器或桌面入口。
- 桌面默认页改为“综合实验工作台”。浏览器中的酶动力学、发酵与 FBA
  按钮通过 Qt 信号切换桌面面板；独立 Web 服务显示打开说明。
- qPCR、独立分析与其他浏览器工具均提供“全部实验模块”返回入口。
- 效价、对接、测序及预览的深链接直接选中相应工具。

原有计算、数据、qPCR 八阶段流程、五套设计模板和六套图表主题均保留。
本版不改变项目数据库结构，也不迁移或删除历史实验。0.6.0 发布包保留。

定位为“统一入口 + 各实验专业流程”：共同管理导航，计算与质量标准按实验类型独立。
酶、发酵与 FBA 仍使用原桌面界面；尚未改造成与 qPCR 相同的浏览器全流程。
