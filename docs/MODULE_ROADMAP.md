# 研究方向与模块取舍

评估日期：2026-11-09。这里的“活跃方向”依据近期论文及官方项目资料判断，
不是搜索热度排名。以下是产品建议，尚未实现的新模块不出现在功能完成清单中。

## 优先级 1：实验设计与人参与的条件优化

场景：从温度、反应组分、培养基、底物和酶用量中选择下一批值得做的实验。
复用现有板位、样品、酶/发酵拟合与可追溯记录，串联“设计 → 实测 → 质控 → 下一轮”。
先提供随机化、对照/重复、因子设计与成本约束，再评估贝叶斯优化推荐。

2026 年 RoboChem-Flex 展示了包括生物催化在内的人参与优化和多目标实验；
[原始研究](https://www.nature.com/articles/s44160-026-01053-0)。
[BayBE 官方项目](https://github.com/emdgroup/baybe)已有实验设计和贝叶斯优化能力。
这些证明方向活跃，不证明本软件已具备机器人控制或优化效果。

最小验证：用公开实验表做离线回放，将推荐方法与随机选点/已有设计比较，
固定预算、随机种子和可用历史数据，避免未来数据泄漏；随后用小规模真实实验确认。
先作为可选适配器，不为一个推荐功能引入完整机器人系统或默认安装大型学习栈。

## 优先级 2：数字 PCR 与绝对核酸定量

与现有 qPCR 用户、样品、荧光通道和对照管理最接近。新方向只接收真实仪器的
分区计数或逐分区荧光数据：阳/阴性分区、人工阈值审阅、Poisson 校正、区间、
分区体积、稀释度与单位追溯；与 qPCR 标准曲线结果并列比较。

[2025 年 Nature Protocols 的 qPCR/ddPCR 微生物绝对定量流程](https://www.nature.com/articles/s41596-025-01165-5)
及 [2026 年多重数字 PCR 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC13234817/)
说明其与定量实验直接相关。报告材料应参考
[dMIQE2020](https://doi.org/10.1093/clinchem/hvaa125)。

不能把 Ct 表转换成虚构分区；体积校准、饱和/全阴性边界和阈值不确定性必须保留。
先选一种仪器公开格式，并以厂商结果及有已知浓度的公开数据做对照。
没有可用仪器数据时，优先级低于实验设计。

## 优先级 3：筛选结果到 qPCR 验证的衔接

近期 CRISPR、单细胞与空间扰动筛选很活跃，例如
[2026 年 Spatial Perturb-Seq 原始研究](https://www.nature.com/articles/s41467-026-69677-6)。
适合本项目的是导入上游已经分析好的候选基因/化合物表，保留效应、校正后
显著性、样品/处理标签和出处，再生成可审阅的 qPCR 验证设计，衔接现有效价分析。

这是待验证的产品推断，不把筛选排名或 qPCR 表达变化解释为因果证据。
首版不重做 FASTQ、单细胞、空间组学全流程，也不承诺用 qPCR 证明编辑效率。
验收需要一个公开筛选结果与验证数据的配对案例，检查候选映射及重复/对照设计。

## 当前模块处理

| 模块 | 0.6.7 处理 | 判断依据 |
|---|---|---|
| qPCR | 保留完整主线 | 具备设计、采集、质控、定量与报告上下文 |
| 效价 | 保留主要模块 | 有真实公开曲线基准，可连接筛选与后续验证 |
| 酶动力学 | 保留主要模块 | 实测反应速率与模型比较可接入条件优化 |
| 发酵动力学 | 保留主要模块 | 与培养条件、时间序列和工艺优化契合 |
| FBA | 保留配套分析 | 用于代谢假设与情景比较；不将预测当作实测通量 |
| 数据/图片预览 | 取消独立研究模块定位，移入辅助入口 | 是导入检查能力，独立占据主模块会稀释用途 |
| 简化刚性对接 | 移出主导航，仅保留兼容工具 | 现有评分和刚性搜索不足以支撑药物筛选价值主张 |
| 通用序列比对 | 移出主导航，仅保留兼容工具 | 与完整定量流程关联较弱，尚无专门引物/编辑验证链路 |

本次取消的是主要产品入口及桌面重复导航，不硬删计算库、CLI、API、原始数据
或历史恢复能力。之后若确有使用证据，可把兼容工具改造成更窄的引物验证适配器；
正式删除库/API 前应先公布弃用期和迁移方式。

## 暂不投入

不直接嵌入通用 AI 聊天、蛋白质基础模型、从头药物设计或全套单细胞分析。
它们需要不同的数据、计算资源和验证，现阶段会扩大维护和科学解释负担。
AI 可用于解释已计算的质控证据和帮助整理报告；数值计算、阈值和最终研究判断
仍需可追溯，并在接入任何云模型前说明哪些数据会离开本机。
