# 0.6.6：分子对接结果复核与可信度提示

本轮完成研究人员评估中的第一优先事项：消除对接搜索诊断与审计规则相互矛盾的提示。
八个模块与现有数据保留，技术栈和依赖不变，仅生成本地发布包。

## 判断依据

- DCK-004 使用搜索引擎的诊断状态，不再从前两名姿势的评分差推断收敛。
  评分差保留在检查证据中；相近评分也可能代表并列候选，不能单独证明采样失败。
- 修正 Monte Carlo 末段诊断：按最后三分之一的累计最优评分改善量判断，
  不再误用后面三分之二中的最大单步改善量。搜索路径与评分函数不变。
  该诊断仍是启发式稳定性检查，不能证明全局最优。
- 网格结果显示“网格枚举完成”，不将有限网格完成解释成全局收敛。
- 统一生成“存在阻断问题 / 需要复核 / 未执行审计 / 仅供探索”的使用判断，
  并附结构、搜索盒、搜索预算、随机种子及独立验证等具体建议。
  关闭审计时明确标记未审计，不能产生“全部通过”的结论。
- 盒内占有率和经验评分的正负只作粗略诊断，不能据此确认真实结合口袋或结合能力。

## 页面、桌面与存档

浏览器与桌面共用复核逻辑。浏览器结果顶部展示复核说明，导出的完整 JSON
包含版本化复核结论和逐项检查证据；自动存档保留实际采用的主要搜索默认参数。
姿势表头改为中文，经验评分不使用表示“可靠”的绿色；网格接受率显示为不适用。
图中注明评分为任意单位，将图例移到数据区域上方并为评分标签留白。
图表画廊随页面滚动，减少图中再嵌套滚动的负担。

原记录与备份不修改。恢复缺少新版复核结论的记录时，页面提示重新运行，
不再把旧版 DCK-004 的评分差检查展示成当前可信结论；原检查仍保存在完整历史结果中。
重新运行追加新记录，不覆盖原记录；外部备份仍须在本机复算后才能展示为当前结果。

## 尚未完成

当前仍是简化刚性对接，未替换评分函数，也未新增经过靶点验证的筛选引擎。
本轮未实现仪器直接导入、qPCR 生物学组间统计或跨实验样品关联。
下一优先级是常用仪器数据的直接导入与独立准确性基准。
