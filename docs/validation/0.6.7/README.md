# Public benchmark rerun for 0.6.7

Generated by `scripts/validate_public_data.py` from its commit- and SHA-pinned
public inputs. `summary.json` captures the executing 0.6.7 dependency environment,
actual input hashes, diagnostic metrics and release-gate results. This was a
source execution before the frozen build, so `runtime.build` is null.

`openadmet_curve_results.csv` retains all 509 eligible compounds: 508 evaluated
fits and one excluded design. The three SVGs use fitted curves only. They are
agreement diagnostics, not prospective validation or evidence of independent use.

The CYP3A4 source data are OpenADMET/Octant, CC BY 4.0, pinned at
`58b3d6a63d25b18bee0b68af07cf1a5b30e6cf0d` in
[Octant_CYP_blog_post](https://github.com/OpenADMET/Octant_CYP_blog_post),
[DOI 10.5281/zenodo.21450795](https://doi.org/10.5281/zenodo.21450795).
The derived CSV/figures here report this project's reanalysis of those data;
retain this attribution when reusing them. qPCR/RDML inputs and their separate
licenses are described in `docs/PUBLIC_DATA_VALIDATION.md` and the workbench
example README. This directory does not contain users' experimental data.
