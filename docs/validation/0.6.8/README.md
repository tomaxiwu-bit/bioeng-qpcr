# Public benchmark rerun for 0.6.8

Generated by `scripts/validate_public_data.py` from its commit- and SHA-pinned
public inputs on 2026-11-19. `summary.json` captures the actual executing
software/dependency versions, timestamp, input hashes and release gates.
This source run precedes the frozen build, so `runtime.build` is null.

The detailed CSV retains 509 eligible compounds: 508 evaluated fits and one
excluded design. Figures show agreement diagnostics for the fitted curves.
They do not establish prospective accuracy or independent laboratory adoption.

The CYP3A4 source data are OpenADMET/Octant, CC BY 4.0, pinned at
`58b3d6a63d25b18bee0b68af07cf1a5b30e6cf0d` in
[Octant_CYP_blog_post](https://github.com/OpenADMET/Octant_CYP_blog_post),
[DOI 10.5281/zenodo.21450795](https://doi.org/10.5281/zenodo.21450795).
The CSV and figures are this project's reanalysis; retain that attribution.
qPCR/RDML inputs and their separate licenses are described in
`docs/PUBLIC_DATA_VALIDATION.md` and the workbench example README.
This directory contains no private experimental data.
